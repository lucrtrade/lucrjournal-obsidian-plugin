本表覆盖新闻、关键位、市场分析、Confluence、策略手册和条件。对象关系见 [[context-notes]] 与 [[playbooks-and-criteria]]。

## 条目字段

| 字段 | 适用对象 | 含义 | 取值或说明 |
| --- | --- | --- | --- |
| `名称` | 新闻、关键位、市场分析、Confluence、策略手册、条件 | 条目的名称。 | 清洗后的名称通常成为文件名；同名文件冲突时拒绝创建。 |
| `描述` | 关键位、市场分析、Confluence、策略手册 | 一段简短说明。 | 去除首尾空格；空白保存为空。 |
| `来源链接` | 新闻创建表单 | 新闻来源网页。 | 接受有效的 HTTP 或 HTTPS 地址，也可以留空。 |
| `日期` | 新闻、关键位、市场分析、Confluence 列表 | 条目的创建时间。 | 只展示，可用于日期筛选。 |
| `标题` | 新闻、关键位、市场分析、Confluence 列表 | 文件名对应的显示标题。 | 改名会改文件路径；链接更新依赖 Obsidian 的文件改名行为。 |
| `来源` | 新闻列表 | 已保存来源链接的列表展示。 | 与创建时的`来源链接`是同一来源值，可在列表修改。 |
| `影响` | 新闻 | 新闻影响等级。 | `高`、`中`、`低`或空。 |
| `标签` | 新闻、关键位、市场分析、Confluence | 用于搜索和筛选的标签。 | 比较时忽略开头的 `#` 和大小写；空列表保存为空。 |
| `公开` | Confluence | 是否进入公开 Confluence 列表。 | 从仓位直接创建时默认为公开；由策略手册补建时默认为不公开。 |
| `条件` | Confluence、策略手册 | 条件分组的名称或链接。 | 名称会清洗并按忽略大小写去重；Confluence 列表中的该列只读。 |
| `策略手册 Confluence` | 策略手册 | 条件分组及其包含的 Confluence。 | 条件分组内至少有一个 Confluence 才会保存；条件名和整本手册内的 Confluence 名都不能重复。 |

> [!WARNING]
> 保存`策略手册 Confluence`会用当前结构化条件和 Confluence 重建 frontmatter 后的全部正文。普通段落、非结构化标题、注释和代码块不会保留。

## 统计字段

| 字段 | 适用对象 | 计算口径 | 无样本时 |
| --- | --- | --- | --- |
| `关联仓位` | 新闻、关键位、市场分析、Confluence | 成功解析到该条目文件的全部仓位数量；不要求仓位已平仓，也不要求净利润有效。 | `0`。 |
| `交易笔数` | 策略手册 | 成功解析到该策略手册文件的全部仓位数量。 | `0`。 |
| `胜率` | 策略手册及共用表现统计 | 只在已平仓且`净利润`为非零数字的仓位中，计算盈利仓位数 ÷ 样本数。 | `0`。 |
| `净利润` | 策略手册及共用表现统计 | 只累加已平仓且`净利润`为非零数字的仓位，并按金额精度舍入。 | `0`。 |
| `最大盈利` | 策略手册及共用表现统计 | 上述表现样本中的最大正`净利润`。 | 空。 |
| `最大亏损` | 策略手册及共用表现统计 | 上述表现样本中的最小负`净利润`。 | 空。 |

因此，`关联仓位`或`交易笔数`的数字可能大于胜率和盈亏使用的样本数：前者纳入全部已解析关联仓位，后者排除未平仓、净利润为空、无效或等于 0 的仓位。
