本页把仓位字段分成原始字段和派生字段。填写位置与页面布局见 [[position-details]]；这里仅列字段口径。

## 原始与关联字段

| 字段 | 来源 | 含义 | 取值或说明 |
| --- | --- | --- | --- |
| `ID` | 系统生成 | 仓位的稳定身份。 | 使用 UUID v7；只展示，不等于 `POS-00001.md` 一类文件序号。 |
| `账户` | 创建时选择，之后由系统推导 | 创建仓位和限定标的候选的账户。 | 必须匹配现有账户。创建后显示值只从当前 `标的` 反查，仓位中的旧账户字段不生效。 |
| `标的` | 用户选择或输入 | 仓位关联的交易品种。 | 保存为标的文件链接；它决定账户、类型、合约单位和手续费模型。 |
| `方向` | 创建时选择 | 交易方向。 | `做多` 或 `做空`。创建后不可修改。 |
| `状态` | 系统初始化，用户可切换 | 仓位当前是开仓还是平仓。 | 新仓位为 `开仓`。写入有限数字的 `出场价` 会改成 `平仓`，但不会自动补 `平仓时间`。 |
| `入场价` | 用户填写 | 所有金额和 R:R 公式使用的唯一入场价格。 | 必须是有效正数才能形成有效计算数量。没有均价字段。 |
| `出场价` | 用户填写 | 实际退出价格。 | 有限数字会把状态改成 `平仓`；清空不会自动重新开仓。 |
| `数量` | 用户填写 | 加密货币仓位的规模。 | 可输入美元金额，或切换为 `原生资产` 数量；原生资产模式需要正数和有效 `入场价`。 |
| `合约` | 用户填写 | 期货仓位的张数。 | 1–20 的整数。 |
| `手数` | 用户填写 | CFD差价合约仓位的手数。 | 0.01–20。 |
| `手续费` | 系统派生，也可手填 | 当前仓位的绝对手续费。 | 标的费率和规模有效时自动计算；手填值会保留到相关源字段再次变化。 |
| `开仓时间` | 系统初始化，用户可改 | 仓位开始时间。 | 新仓位使用当前时区的秒级时间。 |
| `平仓时间` | 用户填写 | 仓位结束时间。 | 可以独立于 `状态` 和 `出场价` 存在；非空时仓位也按已平仓处理。 |
| `置信度` | 用户填写 | 主观评分。 | 1–5 的整数；用于筛选，不参与盈亏公式。 |
| `目标价` | 用户填写 | 计划退出价格。 | 做多时应高于 `入场价`，做空时应低于 `入场价`。 |
| `止损` | 用户填写 | 计划止损价格。 | 做多时应低于 `入场价`，做空时应高于 `入场价`。 |
| `笔记` | 用户填写 | 仓位正文中的自由记录。 | 新仓位正文固定从 `Notes` 分区开始；不是 frontmatter 字段。 |
| `附件` | 用户添加 | 截图等证据文件。 | 仓位保存附件链接；直接删除仓位不会自动清理附件文件。 |
| `策略手册` | 用户关联 | 当前仓位采用的策略手册。 | 保存为单个策略手册文件链接。 |
| `新闻` | 用户关联 | 与仓位有关的新闻上下文。 | 以仓位正文对应分区中的链接标题保存。 |
| `关键位` | 用户关联 | 与仓位有关的关键价位上下文。 | 以仓位正文对应分区中的链接标题保存。 |
| `Confluence` | 用户关联 | 当前交易出现的条件组合。 | 没有关联策略手册时只能选择公开条目。 |
| `市场分析` | 用户关联 | 与仓位有关的市场分析上下文。 | 以仓位正文对应分区中的链接标题保存。 |
| `分析` | 系统汇总 | 仓位表中新闻、关键位、Confluence 与市场分析的合并展示。 | 只展示关联结果，不是独立保存的仓位字段。 |

## 派生字段

公式中的方向值为：`做多 = +1`，`做空 = -1`；有效数量统一为 `名义价值 ÷ 入场价`。

| 字段 | 由什么算出 | 精确口径 | 可否手填 |
| --- | --- | --- | --- |
| `名义价值` | `类型`、规模、`入场价` 和 `合约单位`。 | 加密货币原生资产为 `数量 × 入场价`；期货为 `合约 × 入场价 × 合约单位`；CFD差价合约为 `手数 × 入场价 × 合约单位`。 | 可以修改；相关源字段变化后仍可被重新派生。 |
| `净利润`（仓位表显示为 `收益`） | `入场价`、`出场价`、方向、有效数量和 `手续费`。 | `(出场价 - 入场价) × 方向 × 有效数量 - 手续费`。手续费只扣一次；无效或缺失手续费按 0。 | 可以修改；相关源字段变化后仍可被重新派生。 |
| `风险` | `入场价`、`止损`、方向和有效数量。 | `(入场价 - 止损) × 方向 × 有效数量`；必须大于 0，且不计手续费。 | 界面只读。 |
| `计划 R:R` | `目标价` 相对 `入场价` 的方向收益，以及同一组源字段重新计算的风险。 | 不使用已保存或手填的 `风险`，不计手续费；目标收益必须大于 0。 | 只读。 |
| `实际 R:R` | `出场价` 相对 `入场价` 的方向变动，以及同一组源字段重新计算的风险。 | 不使用已保存的 `净利润` 或 `风险`，不计手续费；亏损结果保留负数。 | 只读。 |
| `持仓时长` | `开仓时间` 与 `平仓时间`。 | 两个时间都有效时显示它们之间的时长。 | 只读。 |

所有金额派生值在完整算式结束后最多保留 8 位小数；绝对值小于 `0.00000001` 的结果归零。全部盈亏、风险与 R:R 公式都只使用 `入场价`，没有平均入场价概念。

> [!WARNING]
> `数量`、`合约`、`手数`、`入场价` 或标的 `合约单位` 失效后，如果公式算不出新值，旧 `名义价值` 不会被清空。新手续费无法派生或算得 0 时，旧 `手续费` 也会保留，并继续参与 `净利润` 计算。改坏或移除源字段后，必须重新核对 `名义价值`、`手续费`、`净利润` 和 `风险`。
