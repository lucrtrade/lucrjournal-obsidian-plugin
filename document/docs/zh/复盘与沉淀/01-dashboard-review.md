## 仪表盘是什么

仪表盘是 LucrJournal 的复盘入口。它把汇总、仓位、上下文和策略手册放在同一条导航中。先缩小样本，再打开具体仓位，不需要在文件夹里逐个找文件。

| 区域 | 先看什么 | 什么时候进入 |
| --- | --- | --- |
| `概览` | `胜率`、`净利润` 和日历中的每日结果 | 先确定要检查的时间段。 |
| `仓位` | 每笔交易的状态、标的、账户、收益和开仓时间 | 找到需要复盘的具体交易。 |
| `新闻` | 外部事件及其关联仓位 | 检查事件是否反复影响交易。 |
| `分析` | `关键位`、`Confluence` 和 `市场分析` | 比较同一种背景下的仓位。 |
| `策略手册` | 一类交易形态的样本和表现 | 把重复结论沉淀成规则。 |

页头右侧的 `全部账户` 用于选择账户范围。第一次复盘时先保留全部账户；只有在比较账户差异时再缩小范围。

## 从概览缩小时间范围

`概览` 提供 `周`、`月`、`季`、`年` 和 `全部时间`。先选与你的问题匹配的范围：检查最近执行用周或月，检查策略是否长期有效再用季、年或全部时间。

日历按日期显示交易结果。选中某一天后，仪表盘会进入 `仓位` 并只显示开仓日期匹配的记录。这样可以从某天的异常结果直接回到当天的交易。

> [!TIP]
> 不知道从哪里开始时，先找净利润明显异常的一天，再核对当天收益最大和最小的仓位。

## 在仓位表找到具体交易

`仓位` 表上方的 `搜索标的...` 不只搜索标的。它实际匹配当前仓位解析出的账户、平台和标的。

- 搜索前会忽略首尾空格和大小写。
- 不加引号的词只匹配完整值或 Unicode 单词开头。例如，`BTC` 可以匹配以 BTC 开头的标的。
- 加引号的内容按连续片段匹配。例如，`"USDT"` 可以匹配名称中间的 USDT。
- 输入多个词时，每个词都必须命中；不同词可以分别命中账户、平台和标的。

漏斗图标打开 `筛选仓位`。搜索和所有已应用的筛选条件必须同时满足。

| 筛选项 | 实际纳入的仓位 |
| --- | --- |
| `状态` | `持仓中` 只看开仓记录；`盈利` 只看已平仓且 `profit >= 0.01`；`亏损` 只看已平仓且 `profit <= 0`。 |
| `方向` | `做多` 或 `做空` 精确匹配。 |
| `置信度` | `高 (4-5)`、`中 (3)`、`低 (1-2)` 按保存的数值分组。 |
| `账户`、`交易对` | 精确匹配；更换账户后，不属于该账户的标的会被清空。 |
| `策略手册`、`新闻`、`分析` | 只纳入 Obsidian 已解析到对应文件的仓位。 |

修改筛选草稿后，选择 `显示结果` 才会应用。直接点筛选框外会丢弃本次修改。`重置全部` 恢复默认筛选。搜索、筛选或排序变化后，表格会回到第一页。

> [!NOTE]
> 已平仓且净利润大于 0、小于 0.01 的仓位既不属于 `盈利`，也不属于 `亏损`。不要用这两个筛选的行数代替完整的已平仓笔数。

## 排序和列布局怎样工作

只有可排序的列标题会改变顺序。账户、标题、标签和条件等文本使用当前语言的文本顺序；手续费、合约单位等数值按数值比较；其他列按单元格值比较。多个排序条件结果相同时，原来的行顺序保持不变。

选择 `列` 可以隐藏或显示列，但不能重新排列。列顺序由 LucrJournal 固定声明，隐藏只是在固定顺序中移除对应列。

可见性按表格分别保存在插件设置中，不写入仓位或上下文 Markdown。`仓位` 默认只隐藏 `分析` 列；`新闻`、`Confluence`、`关键位` 和 `市场分析` 默认不隐藏列。下次打开时会恢复各表自己的隐藏状态。

## 哪些单元格可以直接修改

可编辑单元格会直接写回源文件，不是临时表格批注。

| 表格 | 可直接修改的列 | 写回位置 |
| --- | --- | --- |
| `仓位` | `收益`、`置信度`、`开仓时间` | 分别写入仓位的 `profit`、`confidence`、`opened_at`；清空开仓时间会删除该字段。 |
| 设置中的 `账户` | `账户名称` | 写入账户的 `name`。 |
| 设置中的 `标的` | `类型`、`手续费`、`合约单位` | 分别写入 `type`、`fee_value`、`contract_unit`；合约单位只接受空值或正整数。 |
| `新闻` 与 `分析` | `标题`、`标签`，以及新闻的 `来源` | 标题会重命名文件并同步一级标题；标签写入 `tags`；来源写入 `source`。 |

`Confluence` 表中的 `条件` 当前只读。需要修改策略手册结构时，进入 `策略手册` 的结构化界面。

## 从汇总回到一笔仓位

一次最短的定位流程是：

1. 在 `概览` 选择时间范围或日期。
2. 进入 `仓位`，用搜索和 `筛选仓位` 缩小样本。
3. 选择可排序的 `收益` 或 `开仓时间` 列，先看极端结果或最近交易。
4. 选择一行，打开这笔交易的仓位详情。
5. 回看 `执行详情`、`时间`、`风险与收益`、`笔记` 和关联上下文。

从 `新闻` 或 `分析` 里的 `关联仓位`，以及策略手册详情里的 `交易笔数`，也可以回到已按该条目筛选的仓位表。继续阅读 [[review-workflow]]，把这条路径变成一次完整复盘。
