## 这页是什么

仓位详情是单笔仓位的工作区。你在这里补执行信息、查看风险与收益、写笔记、添加上下文、关联策略手册、保存截图和处理 OCR。

把它当成这笔交易的复盘中心，而不是普通表单。

## 主要区域

| 区域 | 用途 |
| --- | --- |
| 执行详情 | 记录账户、标的、方向、价格、数量和费用。 |
| 时间 | 记录开仓、结束和持仓时长。 |
| 风险与收益 | 查看净利润、风险、计划盈亏比、实际盈亏比等结果。 |
| 笔记 | 写下当时的判断、执行过程和复盘结论。 |
| 上下文 | 关联新闻、关键位、市场分析和 Confluence。 |
| 附件 | 保存截图证据，必要时使用 OCR。 |
| 策略手册 | 关联交易形态，并回看检查项。 |

## 先写事实，再写解释

推荐顺序：

1. 先补执行详情。
2. 再补时间和风险与收益。
3. 写原始笔记。
4. 添加截图或附件。
5. 关联新闻、关键位、市场分析或 Confluence。
6. 最后关联策略手册。

> [!warning]
> 不要让策略手册替代原始记录。先记录这笔交易发生了什么，再整理它属于哪类交易形态。

## 删除仓位前

删除仓位会移除这条仓位记录。截图和关联上下文的影响取决于它们是否还被其他记录引用。

> [!warning]
> 删除前先确认这笔仓位是否还要保留为统计、复盘或策略手册样本。
