## 仓位详情是什么

仓位详情是一笔交易的工作台。页头固定显示标的、方向、标的类型、ID 和账户；下方把行情、证据、执行事实、派生结果与复盘正文放在同一页。

`方向` 是创建时确定的只读信息。账户由当前关联标的推导。点击 ID 可以 `在新标签页中打开源文件`。

## 页面有哪些区域

| 区域 | 显示和处理的内容 |
| --- | --- |
| `图表` | 当前标的的行情，以及入场和出场标记。 |
| `附件` | 交易截图和其他图片证据。 |
| `净利润` | 当前派生或手动写入的交易结果。 |
| `执行详情` | `状态`、`入场价`、`出场价`、数量字段和 `手续费`。 |
| `时间` | `开仓时间`、`平仓时间` 和可派生的 `持仓时长`。 |
| `风险与收益` | `目标价`、`止损`、`置信度`、`风险`、`计划 R:R` 和 `实际 R:R`。 |
| `笔记` 与上下文标签页 | 原始笔记，以及新闻、关键位、Confluence、市场分析和策略手册。 |

窗口较窄时，这些区域会改为纵向排列，内容和计算口径不变。

## 补全执行事实

执行事实是实际发生的价格、规模和时间。点击对应值即可编辑。

| 字段 | 怎么填 | 限制和影响 |
| --- | --- | --- |
| `状态` | 在 `开仓` 和 `平仓` 之间切换。 | 写入有限数字的 `出场价` 也会自动改为 `平仓`，但不会补 `平仓时间`。 |
| `入场价` | 填公式使用的入场价格。 | 系统只有一个入场价，不计算平均入场价。 |
| `出场价` | 平仓后填实际出场价格。 | 清空出场价不会自动重新开仓。 |
| `数量` | 加密货币仓位填写美元或 `原生资产` 数量。 | 只有正的名义价值和入场价才能形成有效计算数量。 |
| `合约` | 期货仓位填写合约张数。 | 必须是大于 0 的整数。 |
| `手数` | CFD 仓位填写手数。 | 必须在 0.01 到 20 之间。 |
| `手续费` | 填这笔仓位的绝对手续费。 | 标的有有效手续费模型时，相关规模变化可能重新派生它。 |
| `开仓时间`、`平仓时间` | 填带时区的实际时间。 | 两者都有值时才会显示完整 `持仓时长`。 |
| `目标价`、`止损` | 填计划价格。 | 做多要求目标价高于入场价、入场价高于止损；做空顺序相反。 |
| `置信度` | 用 1 到 5 的整数记录主观评分。 | 它用于复盘筛选，不参与盈亏公式。 |

> [!NOTE]
> `状态`、`出场价` 和 `平仓时间` 可以暂时不一致。补完平仓信息后应同时核对三项。完整边界见 [[position-lifecycle]]。

`风险`、`计划 R:R` 和 `实际 R:R` 是只读派生值。`净利润` 可以手动修改，但下一次相关源字段变化仍可能覆盖手动结果。

## 读懂派生值

派生值是根据当前源字段计算并写回的结果。这里的“数量”统一指 `名义价值 ÷ 入场价` 形成的有效数量。

| 结果 | 口径 |
| --- | --- |
| `净利润` | `(出场价 - 入场价) × 方向 × 数量 - 手续费`。做多方向为 +1，做空为 -1。绝对手续费只扣一次。 |
| `风险` | `(入场价 - 止损) × 方向 × 数量`。结果必须大于 0，不计手续费。 |
| `计划 R:R` | 目标价相对入场价的方向收益 ÷ 重新计算的风险。它忽略已保存或手填的风险，也不计手续费。 |
| `实际 R:R` | 出场价相对入场价的方向变动 ÷ 重新计算的风险。它忽略已保存的净利润和风险，也不计手续费；亏损会显示负数。 |

所有公式只使用唯一的 `入场价`。LucrJournal 没有分批成交后的平均入场价模型。

例如，做多仓位的入场价为 100，名义价值为 1,000，止损为 95，目标价为 110，出场价为 108，手续费为 2：

- 数量是 10。
- `净利润` 是 78，手续费只扣一次。
- `风险` 是 50。
- `计划 R:R` 是 2，`实际 R:R` 是 1.6；两者都不受手续费影响。

> [!WARNING]
> 数量、`入场价` 或标的的 `合约单位` 变成缺失或无效后，如果公式无法得到新结果，旧的 `名义价值` 不会自动清空。新的手续费无法派生时，旧 `手续费` 也会保留，并继续参与 `净利润` 等后续计算。移除或改坏源数据后，必须重新核对 `名义价值`、`手续费`、`净利润` 和 `风险`。

## 写笔记和关联上下文

`笔记` 是仓位正文的固定起点。先记录交易理由、执行偏差和复盘结论，再用内容区右侧的加号添加 `新闻`、`关键位`、`Confluence` 或 `市场分析` 标签页。

每个上下文条目可以选择已有文件，也可以创建新文件。移除关联区块只会从当前仓位正文中移除该区块，不会删除原始关联文件。`策略手册` 用于关联交易形态和检查项，详细用法见 [[playbooks-and-criteria]]。

> [!TIP]
> 先写这笔交易独有的事实，再关联可复用内容。上下文的边界和统计口径见 [[context-notes]]。
