## 图表、附件和 OCR 的区别

图表、附件和 OCR 不是同一件事。

| 能力 | 用途 |
| --- | --- |
| 图表 | 查看标的价格走势。 |
| 附件 | 保存交易截图、订单截图、复盘图片或其他证据。 |
| OCR | 从图片里识别可能写入仓位的字段，减少手工输入。 |

附件是证据。OCR 是辅助录入。不要把 OCR 识别结果当作自动正确。

## 添加图片证据

1. 打开一笔仓位。
2. 在附件区域选择添加图片。
3. 选择截图或粘贴图片。
4. 保存后，在附件区域检查图片是否能打开。

适合保存的图片包括：

- 入场前的图表截图。
- 出场后的图表截图。
- 券商或交易所的订单截图。
- 盘前计划或盘后复盘图。

## 使用 OCR

OCR 适合从截图里提取可能的仓位字段。使用前先确认图片清晰、方向正确、字段完整。

1. 打开附件。
2. 运行 OCR。
3. 在复核阶段检查识别结果。
4. 只应用你确认正确的字段。

%% ![[screenshot-ocr-import-modal.png]] %%

> [!warning]
> OCR 可能识别错价格、数量或方向。应用到当前仓位前，必须人工检查。

## 删除附件

删除附件前，先判断这张图是否还被其他仓位使用。如果它是唯一证据，建议先确认复盘已经完成。

## 结果检查

- [ ] 图片能在当前仓位里打开。
- [ ] 图片能解释这笔交易当时的背景或执行。
- [ ] OCR 结果已经人工确认。
- [ ] 不需要的截图已经清理。
