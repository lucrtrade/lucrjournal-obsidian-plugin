LucrJournal 是运行在 Obsidian 里的交易日志。你可以把仓位、截图证据、新闻、分析、策略手册和复盘结论放在同一个本地标记语法工作流里。

## 你可以用它做什么

- 记录每一笔仓位的账户、标的、方向、入场、出场、风险与收益。
- 在单笔仓位里补充笔记、截图、上下文和策略手册。
- 从概览、仓位、新闻、分析和策略手册回看历史交易。
- 把重复出现的交易形态沉淀成策略手册和检查项。
- 把记录保存在当前 Obsidian 笔记库中，继续使用 Obsidian 的搜索、链接和文件管理。

%% ![[screenshot-overview.png]] %%

> [!warning]
> LucrJournal 不是券商、下单终端、实时盯盘工具或投资建议工具。它只负责记录和复盘，不替你判断交易方向。

## 推荐阅读路径

1. 先读 [[quickstart]]，完成第一次打开和最小初始化。
2. 再读 [[accounts-and-settings]]，准备第一个账户和标的。
3. 继续读 [[record-first-position]]，创建第一条仓位记录。
4. 读 [[position-details]]，理解单笔仓位的工作区。
5. 读 [[dashboard-review]]，开始每天复盘。
6. 遇到短问题时，直接看 [[q-and-a]]。

## 章节怎么读

| 章节 | 适合什么时候读 |
| --- | --- |
| 开始使用 | 第一次打开 LucrJournal，准备账户和标的。 |
| 仓位记录 | 需要创建、补全、截图、文字识别或复用模板。 |
| 日常复盘 | 每天或每周回看交易记录。 |
| 核心概念 | 需要理解上下文、策略手册、检查项和 Confluence 的边界。 |
| 常见问题 | 想快速确认一个常见问题。 |
| 数据与设置 | 需要处理导入、本地文件、语言、时区或偏好。 |

## 先记住这条线

> [!tip]
> 先把仓位记录清楚，再补证据和上下文，最后把重复结论写回策略手册。

LucrJournal 的价值来自持续记录。第一天不需要用完所有功能，只需要完成一条可回看的仓位。
