## 为什么要拆出上下文

单笔仓位里有笔记，但不是所有信息都应该写进同一笔仓位。

上下文笔记保存能解释多笔交易的背景。这样新闻、关键位、市场分析和 Confluence 可以被多笔仓位复用。

## 笔记和上下文的区别

| 内容 | 放在哪里 |
| --- | --- |
| 这笔交易为什么入场 | 仓位笔记 |
| 这笔交易执行时发生了什么 | 仓位笔记 |
| 一个事件影响了多笔交易 | 新闻 |
| 一个价格区域反复被观察 | 关键位 |
| 一段市场判断会被多次引用 | 市场分析 |
| 多个信号共同支持一个交易形态 | Confluence |

仓位笔记回答“这笔交易发生了什么”。上下文回答“这笔交易处在什么背景里”。

## 新闻

新闻适合记录外部事件、来源和影响。它可以关联到多笔仓位。

用新闻记录：

- 经济数据。
- 公司事件。
- 政策或突发消息。
- 对市场情绪有影响的来源内容。

## 关键位和市场分析

关键位适合保存价格区域。市场分析适合保存你对结构、趋势或环境的判断。

如果一段内容只解释一笔仓位，写在仓位笔记里。如果它会被后续交易反复引用，保存成独立上下文。

## Confluence

Confluence 用来记录多个信号共同出现的状态。它通常不是单一原因，而是一组条件的组合。

例如：

- 价格接近关键位。
- 新闻方向一致。
- 市场分析支持同一方向。
- 策略手册里的检查项被满足。

## 删除影响

移除仓位里的上下文链接，不等于删除原始上下文文件。删除原始上下文前，先确认是否还有其他仓位需要它。

> [!warning]
> 能被多笔仓位复用的内容，不要轻易当作单笔笔记删除。
