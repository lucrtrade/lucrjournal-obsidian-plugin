## What problem they solve

A position has Notes, but not every piece of information belongs inside one position.

Context notes store background that can explain multiple trades. News, Key Level, Market Analysis, and Confluence can then be reused across positions.

## Notes versus context

| Content | Put it in |
| --- | --- |
| Why you entered this trade | Position Notes |
| What happened during this trade | Position Notes |
| One event affected multiple trades | News |
| One price area was watched repeatedly | Key Level |
| One market view may be referenced again | Market Analysis |
| Multiple signals supported one setup | Confluence |

Position Notes answer "what happened in this trade". Context answers "what background was this trade inside".

## News

News is for external events, sources, and impact. One News item can link to multiple positions.

Use News for:

- Economic data.
- Company events.
- Policy or breaking events.
- Source material that affected market sentiment.

## Key Level and Market Analysis

Key Level stores a price area. Market Analysis stores your view of structure, trend, or environment.

If the content explains only one position, write it in position Notes. If you will reference it in later trades, save it as context.

## Confluence

Confluence records a state where multiple signals appear together. It is usually not one reason. It is a combination of conditions.

Example:

- Price is near a Key Level.
- News direction agrees.
- Market Analysis supports the same direction.
- Playbook criteria are met.

## Deletion impact

Removing a context link from a position does not delete the original context file. Before deleting original context, confirm whether other positions still need it.

> [!warning]
> Content that can be reused by multiple positions should not be treated as disposable single-position Notes.
