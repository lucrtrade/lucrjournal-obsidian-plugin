## What it is

Position details is the workspace for a single position. Use it to complete execution data, review risk and reward, write Notes, add context, link Playbooks, store screenshots, and review OCR results.

Treat it as the review center for one trade, not as a simple form.

## Main areas

| Area | Use it for |
| --- | --- |
| Execution details | Record Account, Symbol, side, prices, size, and fees. |
| Timing | Record opened time, closed time, and duration. |
| Risk and reward | Review Net Profit, Risk, planned R:R, real R:R, and related results. |
| Notes | Write the trade idea, execution process, and review conclusion. |
| Context | Link News, Key Level, Market Analysis, and Confluence. |
| Attachments | Store screenshot evidence and use OCR when needed. |
| Playbook | Link the setup and review criteria. |

## Write facts before explanations

Recommended order:

1. Complete Execution details.
2. Complete Timing and Risk and reward.
3. Write raw Notes.
4. Add screenshots or attachments.
5. Link News, Key Level, Market Analysis, or Confluence.
6. Link a Playbook last.

> [!warning]
> Do not let a Playbook replace the raw record. First record what happened in this position, then organize which setup it belongs to.

## Before deleting a position

Deleting a position removes that position record. The effect on screenshots and linked context depends on whether other records still use them.

> [!warning]
> Before deleting, confirm whether the position is still needed for stats, review, or Playbook samples.
