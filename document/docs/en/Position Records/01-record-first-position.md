## Before you start

Before creating your first position, confirm that you have:

- One Account.
- One Symbol.
- The rough side and time of the trade.

The first position does not need to be complete immediately. Save the facts that identify the trade, then return to Position details to add Notes and evidence.

## Create the position

1. In Journal, choose New Position.
2. Select the Account.
3. Select or enter the Symbol.
4. Fill the side, entry, exit, size, or whatever you can confirm now.
5. Save the position.

%% ![[screenshot-new-position-modal.png]] %%

After saving, LucrJournal opens the position details page. This is the main workspace for reviewing a single trade.

## What to complete first

Complete these first:

- Execution details: entry, exit, size, fees, and result.
- Timing: opened time and closed time.
- Risk and reward: risk, planned R:R, and real R:R.
- Notes: why you took the trade, what you saw, and where the result differed from the plan.

> [!tip]
> If you only have time for one thing, write Notes first. Numbers can be completed later. The decision process fades fastest.

## When to use a template

Position Templates are useful for repeated structure. You can skip templates for your first position.

When you notice that you keep writing the same checklist, screenshot placeholders, or review questions, read [[templates]].

## Check the result

- [ ] The position appears in Positions.
- [ ] Opening it shows Position details.
- [ ] You can explain which Account and Symbol it belongs to.
- [ ] You have written one raw Note.
