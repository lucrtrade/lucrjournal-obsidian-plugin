## How charts, attachments, and OCR differ

Charts, attachments, and OCR are different tools.

| Tool | Use it for |
| --- | --- |
| Chart | Review the Symbol price movement. |
| Attachment | Store trade screenshots, order screenshots, review images, or other evidence. |
| OCR | Detect possible position fields from an image and reduce manual entry. |

Attachments are evidence. OCR is input assistance. Do not treat OCR output as automatically correct.

## Add image evidence

1. Open a position.
2. In Attachments, choose Add Image.
3. Choose or paste the screenshot.
4. After saving, confirm that the image opens from Attachments.

Useful images include:

- Chart before entry.
- Chart after exit.
- Broker or exchange order screenshot.
- Pre-market plan or post-trade review image.

## Use OCR

OCR is useful when a screenshot may contain fields that can be written to a position. Before using it, confirm that the image is clear, correctly oriented, and complete.

1. Open the attachment.
2. Run OCR.
3. Review the detected result.
4. Apply only fields you have confirmed.

%% ![[screenshot-ocr-import-modal.png]] %%

> [!warning]
> OCR can misread price, size, or side. Review results manually before applying them to the current position.

## Delete attachments

Before deleting an attachment, check whether another position still uses the same image. If it is the only evidence, confirm that the review is complete first.

## Check the result

- [ ] The image opens from the current position.
- [ ] The image explains the trade context, execution, or result.
- [ ] OCR output has been reviewed manually.
- [ ] Unneeded screenshots are cleaned up.
