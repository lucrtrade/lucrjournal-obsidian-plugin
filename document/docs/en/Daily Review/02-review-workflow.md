## Daily review

When you open Journal each day, do not start with a summary. Review in a fixed order:

1. In Overview, check the result for today or this week.
2. In Positions, open trades that need review.
3. Complete Execution details, Timing, and Risk and reward.
4. Write Notes.
5. Add screenshots or attachments.
6. Link News, Key Level, Market Analysis, or Confluence.

Daily review is about saving facts and the decision you had at the time.

## During or after the session

If you do not have time to write a complete record during the session, save at least:

- Account.
- Symbol.
- Side.
- Entry time or exit time.
- One sentence of Notes.

After the session, complete screenshots, Risk and reward, and context.

## Weekly review

Choose a fixed time each week for higher-level review:

1. Change the timeframe in Overview.
2. Find the best position and the worst position.
3. Check whether they link to the same Playbook.
4. Review whether News, Analysis, or Confluence repeats.
5. Write the conclusion back into the Playbook.

> [!tip]
> The output of weekly review is not more notes. It is a clearer checklist for the next trade.

## Use filters to ask why

Filters turn vague impressions into samples.

- Filter by Account to compare trading environments.
- Filter by Symbol to check whether problems happen only in certain markets.
- Filter by Playbook to test whether a setup still works.
- Filter by timeframe to check recent changes.

## Write back to Playbooks

When you see the same issue repeatedly, write it into a Playbook or criteria. For example:

- Confirm whether the Key Level is valid before entry.
- Do not chase the first candle after a News shock.
- Do not create the position if planned R:R is unclear.
