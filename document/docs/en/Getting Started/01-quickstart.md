## Start here

Open Obsidian, then open the Journal view. If LucrJournal does not have an Account yet, it will guide you to create one first.

You do not need a complete trading system before you start. On the first day, prepare one Account, one Symbol, and one position.

## Do the minimum setup

1. Open Journal.
2. Create your first Account.
3. Add one Symbol that you want to record.
4. Create one position.
5. Return to Dashboard and confirm the position appears in Positions.

%% ![[screenshot-overview.png]] %%

> [!info]
> LucrJournal stores records in your current Obsidian vault. You can still use Obsidian search, links, and file management.

## Do only this on day one

- [ ] You can open Journal.
- [ ] You can see Overview, Positions, News, Analysis, and Your Playbooks.
- [ ] You have created one Account.
- [ ] You have created one Symbol.
- [ ] You have saved your first position.

Do not try to finish every setting on day one. Get one real record saved first, then add screenshots, Notes, context, and Playbook links over time.

## Common blockers

- You cannot see the position: check the current Account and filters first.
- You do not have a Symbol yet: add a Symbol before creating a position.
- You are not sure how to fill a field: save the minimum facts first, then complete details later.
- You are not sure what is next: continue with [[accounts-and-settings]].
