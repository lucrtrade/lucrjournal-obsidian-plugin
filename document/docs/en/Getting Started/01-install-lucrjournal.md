## Install Obsidian first

LucrJournal requires Obsidian `1.11.4` or later. Install Obsidian from the [official download page](https://obsidian.md/download), then create or open a vault.

## Install LucrJournal

1. Open a vault in Obsidian.
2. Select [Open the LucrJournal plugin page](obsidian://show-plugin?id=lucrjournal).
3. Follow the plugin page to install LucrJournal, then turn it on in Obsidian settings.
4. Open the command palette and run the LucrJournal command `Open journal`.

%% ![[screenshot-install-lucrjournal.png]] %%

> [!TIP]
> If the link does not open the plugin page, search for `LucrJournal` from Obsidian's plugin browser, then install and turn it on.
