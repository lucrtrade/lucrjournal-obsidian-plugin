## 1. Install Obsidian and create a vault

LucrJournal requires Obsidian `1.11.4` or later. Install Obsidian from the [official download page](https://obsidian.md/download).

The first time you open Obsidian, create a vault. If you already have a folder of Markdown files, you can open it as a vault instead. Give a new vault a name and location, then create it.

![[install-step1.png]]

## 2. Open the plugin browser

After entering a vault, select the gear icon in the lower-left corner to open Obsidian settings. Then use the third-party plugin area in the left sidebar to reach the plugin management page.

![[install-step2.png]]

## 3. Allow third-party plugins and browse

If Obsidian shows a restriction notice for third-party plugins, follow its prompt to allow them first. Then open the browser on the right side of the plugin management page.

![[install-step3.png]]

## 4. Search, install, and turn on LucrJournal

Search for `LucrJournal` in the browser, open the result, and install it. When installation finishes, turn on LucrJournal on the same details page.

![[install-step4.png]]

You can also [open the LucrJournal plugin page](obsidian://show-plugin?id=lucrjournal) directly and skip the manual browser steps.

## 5. Open LucrJournal for the first time

After installation, select the LucrJournal icon in the left sidebar to enter the plugin. The first launch shows the sign-in page. Select `Continue with LucrTrade`, then use [[quickstart]] to sign in, check access, and create your first position.

![[install-step5.png]]

> [!TIP]
> If the LucrJournal icon does not appear in the left sidebar, open the command palette and run the LucrJournal command `Open journal`.

Continue to [[quickstart]] to sign in, check access, and create your first position.
