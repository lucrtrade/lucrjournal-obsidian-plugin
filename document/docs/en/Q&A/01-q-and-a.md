## Where are records stored?

Records live in your current Obsidian vault. You can keep using Obsidian search, links, and file management.

Continue with [[local-files-and-markdown]].

## What should I do on the first launch?

Create an Account first, add a Symbol, then create your first position.

Continue with [[quickstart]].

## What is the difference between Account and Symbol?

An Account is the trading source. A Symbol is what you trade. A position links to both.

Continue with [[accounts-and-settings]].

## Why can I not see a position?

Check the current Account, Symbol, timeframe, and filters first. Also confirm that the position was saved.

Continue with [[dashboard-review]].

## What if OCR is wrong?

Do not apply it directly. Return to review, keep only fields you have manually confirmed, and ignore the rest.

Continue with [[attachments-chart-ocr]].

> [!warning]
> OCR assists input. It does not confirm correctness.

## When should I use a template?

Use a template when you repeatedly record the same position type and need the same questions or structure each time.

Continue with [[templates]].

## When should I use a Playbook?

Use a Playbook when you want to turn one setup type into rules you can review. The live decision for a single trade still belongs in position Notes.

Continue with [[playbooks-and-criteria]].

## Where should News, Key Level, Market Analysis, and Confluence go?

If the content explains only one position, write it in position Notes. If it can be reused by multiple positions, save it as context.

Continue with [[context-notes]].

## What should I check before deleting an Account, Symbol, or position?

Confirm whether linked records still need to be kept. Delete is best for mistaken data, not for organizing long-term history.

Continue with [[accounts-and-settings]] and [[position-details]].

## Can I edit Markdown directly?

Yes, but be careful. Direct editing is good for text fixes and extra Notes. Avoid casual edits that change links, ownership, or stats.

Continue with [[local-files-and-markdown]].
